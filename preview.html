让虚拟设备，真正上云。

电脑就是设备。通过巴法云转发数据和控制消息。

网页演示无需注册。真实巴法云通信需在电脑运行附带的 Python 程序，再在它打开的本地网页填写账号私钥。此在线版不会保存或接收你的私钥。

三步开始真实通信

  1. 下载完整项目并解压。电脑安装 Python 3.10 或更新版本。
  2. 双击 Start_CloudLink.bat（Windows），或运行 python3 server.py。程序会打开电脑上的控制台。
  3. 在巴法云控制台注册账号，在 TCP 创客云中创建两个设备主题：cltelemetry004 和 clcontrol003。把私钥和主题填入右侧表单。

一个主题传数据，一个主题传控制命令。界面收到云端返回的数据后才更新；收到控制命令后虚拟设备才执行。

先看懂，再讲清楚。

三个角色，组成一个完整的物联网软件实验。

这个项目做了什么？

CloudLink Lab 是一个纯软件的物联网设备模拟与监控系统。虚拟设备生成温湿度数据，控制台显示曲线、发送风扇控制命令，并记录执行确认和异常事件。

1 / 虚拟设备 Simulator

用程序代替真实传感器和单片机。风扇也是虚拟的：开启后，温度模型会逐渐降温。

2 / 消息传递 Publish / Subscribe

发布，就是往指定“消息频道”发数据；订阅，就是监听这个频道。这个频道叫 Topic（主题）。本地模式用浏览器内的消息总线；真实模式用巴法云 TCP 服务。

3 / 控制台 Dashboard

接收采样、绘制曲线、导出 CSV；发送指令，等待设备确认后再显示执行结果。

一个 90 秒演示

  1. 打开总览，说明当前是本地仿真还是巴法云真实传输。
  2. 点击风扇开关，观察“等待确认 → 已确认”，以及后续温度变化。
  3. 选择“自动”，把阈值设为 26°C，再点“升温测试”，观察超温与自动开风扇。
  4. 选择“设备离线”，尝试发送命令，观察超时。恢复正常后重试。
  5. 打开数据与事件，查看记录，再导出 CSV。

项目介绍

“我做了一个不依赖实体硬件的物联网软件实验台，用虚拟设备生成数据，实现了实时监控、控制确认、阈值联动和断线测试。演示可以本地运行，也提供了巴法云 TCP 接入程序。”

要准确说明的范围

温湿度和风扇是软件模拟；本地演示没有经过云服务器。只有配置账号并收到云消息后，才属于真实巴法云通信。本项目不包含真实传感器测量，也尚未接入阿里云。

动手练三个小实验

① 把阈值从 30°C 调到 26°C，观察自动模式的变化。② 离线时发送指令，解释为什么按钮不能直接显示成功。③ 开启消息丢失场景，比较“发送次数”和“成功次数”。

建议先按顺序操作一遍，再读源码中的 sendCommand、deviceCommand 和 ingest 三个函数。
