运行方式

Windows 双击 Start_CloudLink.bat。程序持续运行三个虚拟设备，关闭网页仍可采样。停止程序后，私钥随进程内存释放。

系统设计

虚拟设备、消息通道、控制台与数据存储。

从采样到历史记录

Python 进程运行三个独立的环境模型，生成温湿度数据。云模式通过巴法云传递，本地模式通过内存消息队列传递。接收采样后写入 SQLite，网页通过本地 API 查询。

控制回路

创建唯一指令编号 → 发送命令 → 按设备编号分发 → 执行并记录 → 返回同编号回执 → 确认成功。丢失回执时重发原编号，已执行的指令只补发回执。

自动控制

每台节点有自己的阈值和模式。使用 1°C 回差和控制间隔，减少临界温度附近的频繁切换。

可以复现的实验

  1. 选择设备 A 并开风扇，再选择设备 B，查看两者独立的状态和记录。
  2. 设置自动模式与升温场景，观察自动开风扇和报警事件。
  3. 选择设备离线后发送指令，查看 3 次发送尝试与 5 秒超时。
  4. 刷新页面，确认数据库中的采样、指令和设置仍然存在。
  5. 云模式下临时断开网络，观察重连次数与恢复后的新采样。

环境和风扇由软件模拟。云模式的消息经过真实巴法云服务器，本地模式在电脑内部传递。
